# お好みビンゴ！

好きな文章と配置でカードを作る、自由編集型ビンゴ。ランダム抽選はありません。

## 起動と公開

`index.html`、`style.css`、`core.js`、`app.js`を同じ場所に配置してください。ビルド・サーバー・ログイン・外部ライブラリは不要です。安定した保存にはHTTP/HTTPSで利用してください。

GitHub Pages：リポジトリのルートへ4ファイルを置き、Settings → Pages → Deploy from a branch → main / root → Save。公開操作はノガミの承認後に実施します。README・テスト資料は同梱可能です。

## 操作方法

1. カード名を入力し、3×3・4×4・5×5または縦横個別設定を選びます。
2. マスを選択して文章を入力し、「反映する」を押します。日本語・改行・空欄対応。
3. 必要ならFREEを有効にし、任意の位置を指定します。
4. 「プレイする」を押すと編集がロックされます。マスを押してチェック・解除します。
5. 「編集する」で再編集できます。

## 確定仕様

- 縦横各3〜7、最大49マス。正方形は縦・横・2本の斜め、長方形は縦・横のみ。完全な列のみ数え、複数列は合計表示します。
- FREEは1マス、常時チェック済み。元の文章と手動チェックを保持し、無効化すると元に戻ります。
- サイズ変更は左上基準で座標を保持。7×7分の内容・チェックを保存し、隠れた内容は再拡大で復元します。FREE位置が範囲外になった場合は中央付近へ移動します。偶数サイズの初期FREE位置は中央4マスの右下側です。
- カード名100文字、各マス2,000文字まで。HTMLは文字として表示します。長文はマス内でスクロールできます。
- ブラウザのlocalStorageへ入力反映・各操作ごとに自動保存。カード名、サイズ、全49マス、FREE、モード、チェックを保存。保存キーは `nogami-okonomi-bingo-v1`、データ形式はversion 1。
- 保存が失敗すると画面に表示。壊れた保存データを自動上書きせず、手動保存時に確認します。
- チェック全解除と初期化には確認。FREEはチェック全解除の対象外。初期化は全データを空の5×5へ戻します。
- 大きなカードはカード領域だけ横スクロール。マスは約90px以上、操作ボタンは44px以上。キーボード操作・フォーカス表示・状態通知に対応。
- サイトデータ削除、ブラウザ変更、端末変更、プライベートブラウズで保存内容が消える場合があります。複数タブ同時編集では最後の保存が優先されます。

## 構成とメンテナンス

- `core.js`：データ形式・ビンゴ判定・復元検証（DOM非依存）
- `app.js`：操作・描画・保存
- `style.css`：PC・スマートフォン表示
- `tests/`：判定と操作の検証

判定テスト：`node tests/core.test.cjs`。ブラウザテストはPlaywrightが必要です。ルートの親で `python3 -m http.server 8765` を起動して `node tests/browser.test.cjs` を実行。製品自体はPlaywrightに依存しません。

## 拡張候補

PNG出力、カード共有、OBS表示、複数カード管理。初期版には搭載していません。将来の保存形式変更時はversionに応じた移行処理を追加します。
